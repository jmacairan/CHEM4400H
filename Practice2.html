Useful equations and relationships

Retention and selectivity

k′ = (tR − tM)/tM

α = k′2/k′1   (k′2 > k′1)

Resolution

Rs = 2(tR,2 − tR,1)/(w1 + w2)

Baseline resolution is commonly near Rs = 1.5.

Efficiency

N = 16(tR/wb)2

N = 5.54(tR/w1/2)2

H = L/N

van Deemter

H = A + B/u + Cu

Smaller H means a more efficient column.

Flow and GC programs

u = F/A = 4F/(πdi2)

tramp = ΔT/(ramp rate)

Total program time = holds + ramp times.

HPLC gradients and injection

tdwell = Vd/F

minjected = C × V

Acid–base relationships

pH = pKa + log([A−]/[HA])

pH = pKa + log([B]/[BH+])

Proteins in ion exchange

pH > pI → net negative

pH < pI → net positive
